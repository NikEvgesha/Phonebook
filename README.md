# Phonebook

Программа, хранящая в памяти справочник телефонных номеров (имя, номер телефона). При старте заполняет его 100 000 записями. Каждые N миллисекунд у случайного кол-ва записей ищменяется номер телефона на другой. Через T секунд с момента начала программы выводятся в консоль записи, которые находились в справочнике M секунд назад.

N, M, T случайные числа, где 500<N<5000, 0<M<30, 60<T<300

Значение N определяется каждый раз заново перед очередным изменением номеров справочника.
